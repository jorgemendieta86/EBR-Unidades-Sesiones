Flujo simplificado para Primaria

De una programación anual integrada a unidades integradas y sesiones por área.

Sube la programación anual integrada. La plataforma identifica las experiencias planificadas, genera cada unidad con todas las áreas que le corresponden y, después, organiza las sesiones por área curricular.

Paso 2

Genera las unidades integradas

Cada experiencia se convierte en una unidad integrada. La lista muestra el número y la fecha o periodo de trabajo indicado en la programación, para que puedas generar y descargar una unidad específica o todas las unidades en un ZIP.

Paso 3

Genera las sesiones por área a partir de las unidades

Las sesiones nacen de las unidades integradas ya generadas. Puedes ver y generar las sesiones de una sola área o de todas las áreas, respetando la secuencia definida en cada unidad.
